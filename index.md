# Pradera

Pradera es una extensión de VS Code para crear bots y automatizar flujos de trabajo. Permite preparar contenido, revisar el video y el texto completos, elegir una cuenta autorizada y publicar en servicios conectados.

Las conexiones sociales se configuran en **Tools y MCP → Cuentas**. Con **publicar con revisión**, la persona comprueba la pieza y el destino antes del envío. La disponibilidad de una API depende de los permisos y la aprobación de cada plataforma.

- [Información y consultas del proyecto](https://github.com/AlexCode1234/pradera-web)
- [Privacidad](privacidad.html)
- [Condiciones de uso](condiciones.html)

Instagram, Threads, TikTok y YouTube son servicios independientes. Pradera no está afiliada a ellos.
